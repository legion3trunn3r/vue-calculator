# Vue Calculator - Профессиональный веб-калькулятор

Современный и функциональный калькулятор, построенный на Vue 3 + Nuxt 3 + TypeScript с поддержкой темной темы и расширенными возможностями.

## ✨ Возможности

### Основные операции

- ✅ Базовые математические операции (+, -, \*, /)
- ✅ Модуль (%)
- ✅ Степень (^)
- ✅ Поддержка десятичных чисел
- ✅ Обработка ошибок (деление на ноль)

### Продвинутые функции

- 🎮 **Клавиатурная поддержка** - используйте числовую клавиатуру и операторы
- 📋 **История вычислений** - сохранение и восстановление результатов (до 50 записей)
- 💾 **Память (M+)** - временное сохранение значений
- 📋 **Копирование** - быстрое копирование результата в буфер обмена

### Дизайн

- 🌙 **Темная/светлая тема** - автоматическая поддержка системных настроек
- 📱 **Responsive дизайн** - оптимизация для всех устройств
- ✨ **Плавные анимации** - интерактивные кнопки с обратной связью
- 🎨 **Современный UI** - использование Tailwind CSS

## 🛠️ Технологический стек

- **Vue 3** - реактивный фреймворк
- **Nuxt 3** - meta-фреймворк для Vue
- **TypeScript** - типизированный JavaScript
- **Tailwind CSS** - утилитарный CSS фреймворк
- **VueUse** - набор составляемых функций Vue
- **ESLint** - статический анализ кода
- **Prettier** - форматирование кода

## ⌨️ Клавиатурные сочетания

| Клавиша          | Действие                    |
| ---------------- | --------------------------- |
| `0-9`            | Ввод чисел                  |
| `+` `-` `*` `/`  | Операции                    |
| `.` или `,`      | Десятичная точка            |
| `Enter` или `=`  | Вычисление                  |
| `Backspace`      | Удаление последнего символа |
| `Delete` или `C` | Очистка                     |

## 📝 Примеры использования

### Базовое вычисление

1. Нажмите `7` + `3` + `=` → результат: `10`
2. Используйте историю для быстрого повторного использования

### Использование памяти

1. Введите число и нажмите `M+` для сохранения
2. Проведите дополнительные вычисления
3. Значение в памяти сохранится до очистки

### Копирование результата

1. После вычисления нажмите `📋` (кнопка копирования)
2. Результат скопирован в буфер обмена

## 🎨 Кастомизация

### Изменение цветов

Отредактируйте цвета в `components/Calculator.vue` в классах стилей Tailwind:

- `.btn-operator` - цвет оператора
- `.btn-equals` - цвет кнопки равно
- `.btn-clear` - цвет кнопки очистки

### Добавление новых операций

1. Добавьте кнопку в template
2. Добавьте логику в функцию `calculate()`
3. Обновите поддержку клавиатуры если нужно
